# Common icon

`common-icon.png` is the approved orange folded-C mock logo, generated during
the design exploration. Its transparent margins were trimmed and the image
resized to 512 × 512 for application use. The artwork retains transparency.

`BrandIcon` shares this asset between web and desktop sign-in and navigation.
The web document also uses it as its favicon. Company workspace logos remain
separate from the application's identity.
