The Orders change deliberately preserves its current modal, job list and CSV output. It replaces the generic renderer-supplied CSV path with a job identifier and an opaque module session. Leaving the view or changing its account/workspace/release cancels the pending context. The preparation endpoint returns only the authorized filename and adds no download audit entry. A successful server retrieval is audited once; that audit describes delivery of server data, not proof that an operating-system write succeeded.

No original requirement is deferred by this classification. The next implementation step remains a reviewed new Orders capability release and its host integration, followed by complete administrator capability review. Corporate profile, notification, LAN and release gates retain their existing tracker IDs.
