The Orders change preserves its modal, job list and CSV output. Version 2.1.0 retrieves authorized data before invoking its declared file effect; pinned legacy delivery obtains data after file selection through its protected job identifier and opaque session. Leaving the view or changing its account/workspace/release cancels the pending context. The preparation endpoint returns only the authorized filename and adds no download audit entry. A successful server retrieval is audited once; that audit describes delivery of server data, not proof that an operating-system write succeeded.

No original requirement is deferred by this classification. The next implementation step is complete administrator capability review and effective grant explanations. Corporate profile, notification, LAN and release gates retain their existing tracker IDs.
