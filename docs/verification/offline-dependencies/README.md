# Generated offline dependency capture

Status: scoped implementation verified locally, 18 September 2026. OFF-01 remains active; this does not complete conflict resolution or all offline workflows.

## What changed

Generated resource forms can select provisional records created in the same offline working session. Options are visibly marked pending or needing review and are not inserted into accepted server pages. Current source/target resource permissions and the corporate lease still apply. Cross-module provisional choices additionally require a previously successful online lookup for that declared target.

Enqueueing derives prerequisites from the exact verified resource schema, commits them with the request and retained signed response contract, and keeps stable record/retry identifiers. A rejected prerequisite holds only its dependents. Reviewed replacements preserve their target and prerequisites and atomically reconnect dependent entries. Changed retry contents, replacement of uncertain requests and circular dependencies fail without losing saved drafts.

The existing pending-changes interface now explains when a prerequisite is blocking submission. No layout, theme or component styling changed. More complete per-change presentation and conflict comparison remain required in the [OFF-01 map](../../offline-workflows.md).
