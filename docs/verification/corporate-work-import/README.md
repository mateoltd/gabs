# Corporate saved-work import admission

Scope: ID-03-BACKUP-CORPORATE, admission foundation only. This is not a complete product restore flow. User-facing selection, fresh-authentication guidance, inspection, outcome reconciliation and reviewed promotion remain required. No production-facing placeholder was added.

## Implemented contract

`@suite/client/work-import` exposes `parseSavedWorkImport` and `stageSavedWorkImport`. It accepts the existing `module-work-recovery` format generated by saved-request and saved-draft exports. The host supplies the active scope, authenticated client, persistence adapter, cancellation signal and a guard for the active/unlocked workspace and explicit offline-storage consent.

Admission requires online server responses: a recent verified-MFA session, current workspace permissions/module readiness, the trusted registry key, the current release and each original signed release. An account-bound client checks actor headers. A second policy/session read rejects changed policy or authentication context; session expiry, cancellation and the host guard are rechecked immediately before the local write, including after asynchronous artifact persistence. The file cannot supply authority, trusted contracts, credentials or an offline lease.

The exact imported snapshot is stored in `ModuleStorage.recoveryImports`, separate from active requests, drafts, executable packages and receipts. Request identity/body/dependencies, uncertain/accepted/cancelled observations, targets, source versions, comparisons, collision choices and command reviews remain intact. Imported outcome claims do not settle, execute or cancel a server request. A canonical-content fingerprint makes identical/reformatted concurrent imports idempotent. Storage failure leaves the source file and prior destination state unchanged; retry admits a single durable copy. Unresolved imports prevent ordinary offline-storage removal in both IndexedDB and protected SQLite through their shared retention gate.

Inputs are limited to 1 MiB of UTF-8 JSON and 64 object/array nesting levels. A workspace can retain up to 32 imported copies totaling 1 MiB including metadata; exceeding either bound fails explicitly without evicting prior work. The desktop's existing overall cache-value limit still applies. Large/bulk encrypted corporate archives remain separate unfinished work. Existing exports are authorized JSON copies, not newly encrypted corporate backups.
