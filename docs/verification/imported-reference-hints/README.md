## Behavior

Import previously discarded the reference-reassignment context attached to a saved request. The exact original input survived, but later correction no longer explained the changed prerequisite records. Request restoration now retains deduplicated hints from the request and any separate command review. It never rewrites a call, saved input or dependency identity from those hints. A matching record-target observation remains handled by the explicit target selector.

The authoritative server still settles the exact original before restoration. An accepted original receives no new reference hints or executable correction. A stopped request retains the observations for its existing correction form; imported command reviews do not carry confirmed hint context or copied continuation selections, so a correction requires fresh review. The correction remains subject to current authority, and the server validates the submitted business change. Missing prerequisite receipts block correction.

Conflicting destinations for the same source reference fail before server settlement. Existing local recovery and saved reviews remain protected; reviews arriving during asynchronous restoration prevent the local commit. The retained file preserves every original observation. The shared notice identifies the observations as saved reference hints that require review. No styles changed.
