# Portable schema-format acceptance

18 September 2026. SDK-04-FMT is locally verified. This closes the specific format-validation gap that reopened SDK-04; it does not complete the broader UI kit, host capabilities, release operations or overall parity.

## Implemented behavior

- The [portable format contract](../../schema-formats.md) declares 17 string formats using pinned full validators. `field.text` exposes their inferred vocabulary; TypeBox schemas remain intact.
- Assertions, generated-form parsing and nested reference-branch selection use the same validators. Every synchronous check restores the caller's TypeBox registry; application initialization and a shared SDK instance are unnecessary.
- Authoring rejects unsupported formats with the schema path, supported names and guidance to use a pattern. Traversal covers module-owned resource/store/configuration/operation/error/event/service/view schemas and unused branches, without treating default/example data as schemas.
- New format-bearing custom-view bundles carry signed `client.formats` revision 1 requirements. Missing host support yields an actionable compatibility error. Schema serialization, generated documentation, length/pattern constraints and signed integrity are preserved.
- No historical business release, production UI layout or style was edited. The historical pattern-only `field.date()` helper retains its signed behavior; new strict dates explicitly use `format: "date"`.

## Corrections and limits

The initial test fixture imported TypeBox without a root test dependency and used the wrong local-handler API; strict/focused checks caught both. The expanded browser fixture initially opened the default Contacts resource and incorrectly expected DOM custom validity where the local form displays an SDK error alert. It now selects the installed resource explicitly and asserts the real field-path error before correction. The native harness needed Axe's existing Electron-compatible legacy mode and a personal-workspace entitlement in addition to the corporate assignment. No entitlement check or validation rule was weakened. The corrected affected journeys passed; this is cumulative evidence, not a claim that earlier runs were green.

The initial browser captures clipped the top of the long form because submission scrolled to its button. Final captures use a taller wide viewport and scroll the heading into view. Historical structured-form screenshots generated by the regression test were restored to their original bytes.

Native offline testing disables renderer connectivity; it is not an operating-system network-partition test. No OS notification, foreground dialog, production release, remote CI, signing/notarization, load or hosted-provider acceptance was performed. Other parity gates remain tracked separately.
