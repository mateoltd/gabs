# Persistent LAN status

18 September 2026. OPS-01-STATUS and SDK-05; scoped local acceptance only.

## Behavior

The native corporate workspace shows a compact peer count below the scrolling content while its authorized LAN session is enabled. The link opens Local network settings and transfers keyboard focus to that heading. It remains visible at narrow widths and uses existing surface, text and focus tokens. Settings shares the same status and uses correct singular/plural copy.

Electron sends a payload-free invalidation event when listener or peer membership changes. One account/workspace-scoped query feeds both surfaces. Invalidations discard the prior result, cancel earlier responses and read current main-owned status. A previously enabled indicator keeps its link mounted with a checking label during refresh, preserving keyboard focus without presenting an old count. Permission loss, switching to a personal workspace, stop, expiry and logout cannot retain a previous workspace's visible count. A 15-second background local-IPC refresh covers missed events. Browser clients do not display a native status indicator.

The main process retains the existing authority boundaries. The current LAN session still requires administrator authorization; employee/delegated access and offline startup remain required follow-up work. The indicator does not grant capabilities or finalize relayed business changes.

## Verification

The hidden native journey verifies:

- Disabled state before enable, one peer after initial discovery, and matching Settings copy.
- Keyboard activation from a module view, focus transfer and visible settings controls.
- Personal/company workspace switching without leaking the old peer count.
- A second real TLS peer appearing within three seconds, and disappearing after the actual one-minute heartbeat.
- A visible count and no horizontal overflow at 390px width; scoped Axe checks in high-contrast mode.
- Lease revocation and logout remove the indicator within three seconds.

Inspected [wide](wide.png), [narrow](narrow.png) and [high-contrast](contrast.png) captures. These verify this addition and preserve the surrounding design; they are not approval of the product as visually polished or a whole-product AAA claim.
